# 《Big Brother（老大哥）》选手玩家指南

> 适用：本平台「Big Brother」游戏（`/games/bigbrother`）选手端
> 阅读对象：参赛房客（Houseguest）
> 版本：线上实现版（与实体版规则结合，具体以管理员开赛前公布的赛季设置为准）

---

## 一、游戏简介

Big Brother 是一档「同住 + 社交博弈 + 竞赛」的生存类真人秀赛制。所有房客（Houseguest）共同生活在同一栋房子里，每周经历一个固定循环：

**房主竞争（HOH）→ 提名 → 否决权竞争（POV）→ 否决权会议 → 替换提名 → 淘汰投票 → 淘汰**

- **房主（HOH，Head of Household）**：本周的掌权者，拥有提名权。
- **否决权（POV，Power of Veto）**：可以「救下」被提名者的权力。
- **淘汰投票**：由其他房客把一人送出房子，被淘汰者将离场。
- **最终目标**：成为留在最后的 **冠军（Winner）**，或至少进入 **陪审团（Jury）**。

本平台把上述流程完整线上化：所有阶段、比赛、投票、房子内的实时互动都在网页完成，数据由服务器统一判定，选手只需按提示操作。

---

## 二、账号与进入

- 管理员会为每位房客分配 **账号** 与 **密码**。在选手登录页输入账号和密码即可进入游戏。
- 管理员使用独立的管理员登录入口（账号 / 密码）进入管理后台。
- 顶部右上角可 **退出** 登录。
- 「我的资料」页可查看/上传 **头像**、查看自己的属性（脑力 / 体力 / 社交等，如管理员启用）。
- 一次比赛（赛季）内，你会经历多轮（第 1 周、第 2 周……），每轮都有完整的周循环。

## 四、每周标准流程（重点）

每一轮（一周）依次发生以下环节，左侧目录会按顺序开放：

### 1. 房主竞争（HOH Competition）
- 所有有资格的房客一起参加一个小游戏（见第八节）。
- **上一届房主不能参加本周 HOH 竞争**（避免连任；终局 F3 的最终房主除外）。
- 胜者成为本周 **HOH**，获得提名权，并通常可获得 HOH 房的使用权。

### 2. 提名（Nomination）
- HOH 提名若干名房客作为本周「淘汰候选」。
- 默认提名 **2 人**；启用 **三重献祭 / BBBB** 变数时为 **3 人**。
- **提名仪式（钥匙抽取）** 是正式流程：
  1. HOH 先发表「开场发言」（页面提供模板，可修改）。
  2. HOH 从箱中依次抽出钥匙，钥匙上是下一个 **被宣布安全** 的房客姓名；被宣布者再抽下一把。
  3. 所有钥匙抽完后，**没有获得钥匙的人即为被提名者**。
  4. HOH 发表「结束发言」，宣布提名名单与原因。
- 提名仪式发生在 **餐厅**，相关发言会自动记录进餐厅聊天。

### 3. 否决权竞争（POV / Veto Competition）
- 参赛者通常为：**HOH + 被提名者 + 随机抽取的房客**，凑够规定人数。
- 抽卡方式：人数较多时，HOH 与提名者从牌堆中抽取上场；抽到 HOH/被提名者时由其自选一位房客参战。
- 胜者获得 **否决权**。
- 若本周启用「无护符挑战」变数，则跳过本环节，本周无人持有否决权。

### 4. 否决权会议（Veto Ceremony）
- POV 持有者宣布是否使用否决权：
  - **不使用**：提名保持不变。
  - **使用**：救下一名（或按变数规则全部）被提名者，HOH 必须重新提名。
- 若启用「回旋镖护符」变数，使用否决权将救下 **全部** 被提名者。

### 5. 替换提名（Replacement Nomination）
- 仅在否决权被使用时发生：HOH 提名替补房客，补足提名人数。

### 6. BBBB 环节（仅启用该变数的轮次）
- HOH 提名 3 人后、正式淘汰投票前，**3 名被提名者进行一场 BBBB 比赛**。
- 胜者 **立即安全**，其余 2 人进入淘汰投票。
- BBBB 胜者 **可以投票**（不占用提名者的限制）。

### 7. 淘汰投票（Eviction Vote）
- 由 **未被提名** 的房客投票，选出想淘汰的一名被提名者。
- 被提名者通常不能投票；**BBBB 胜者例外**。
- **平票** 时由 **HOH** 投出决定性的一票。

### 8. 淘汰结果（Eviction Result）
- 管理员以「逐句揭晓」的方式宣布结果，选手端实时同步。
- 揭晓句式（三句或五句，由赛况决定）：
  1. `by a vote of X-Y`（票型，大数在前）
  2. `房客姓名`
  3. `你安全了` 或 `你被淘汰了`
  4. （如有第五句）`房客姓名` / `你安全了` 或 `你被淘汰了`
  5. 最后「开门」公布完整票型。
- 被淘汰者离场，视赛程进入 **陪审屋（Jury House）** 或直接出局。

## 五、比赛中的操作要点

### 小游戏（HOH / POV / BBBB）
1. 每场小游戏开始前，制作组会在 **选手独白室（Diary Room）** 说明本场开始时间，并 **召集** 本场选手。
2. 进入比赛页面后点击 **「准备」**，页面会显示全员准备状态与 **开赛等待倒计时**。
3. ==**全员准备后，比赛可能随时开始**；若有人未准备，最多等待 **30 秒**，30 秒后仍未准备也会直接开始；若 30 秒内全员到齐，也会等满 30 秒后开启。**以页面倒计时为准。**==
4. ==**点击「准备」即默认你不会移开当前界面；因切屏至 QQ、微信等错过比赛开始，幕后团队不负责。**==
5. 比赛结果由 **服务器判定**，动画仅用于展示，不会改变结果。部分网页内置小游戏玩法见第九节。==（不代表本赛全部比赛来源）==

### 提名仪式（钥匙抽取）
- 页面会引导 HOH 抽钥匙、发言；被点到的选手页面会提示「你已安全 / 轮到你了」。
- **提名原因**可直接在结束发言模板中修改。
- 提名者在仪式 **结束前不会提前公开**，请按流程进行，保持仪式感。

### 否决权会议
- POV 持有者页面会出现「是否使用否决权」的操作；其余选手观看实时结果。

### 淘汰投票
- 页面列出被提名者，点击其中一人提交投票。
- 票数在揭晓前不会公开；锁票后不可更改。

### 淘汰结果宣布
- 由管理员逐句点击推进，选手端依次显示，直到「开门」公布票型。

## 六、BB House（房子）——最常用的页面

BB House 是选手平时停留与互动的地方，实时同步。

### 1. 地图与房间
房子包含以下区域（房间之间有通道连接）：

| 区域 | 说明 |
|---|---|
| 客厅 / 厨房 / 餐厅 / 健身房 / 储物间 | 公共活动区 |
| 洗漱间 / 浴室 | 洗漱与洗澡（浴室限 2 人） |
| 卧室 A / 卧室 B | 可睡觉（有床位限制） |
| 贫民屋（Have-Not Room） | 所有人课进入 仅「贫民」可在此睡觉 |
| 后院 | 通过客厅的 **后院门** 进出 |
| HOH 房门 / HOH 房 | 房主专属，需门禁/邀请 |
| Diary Room | 单人房间 |
| 初入屋 / 陪审屋 | 特殊隔离区域，仅管理员可安排进出 |

### 2. 移动
- 点击地图中 **可达** 的房间即可前往；不可达房间会置灰。
- 门关闭时（如后院门、HOH 房门），无法通过。

### 3. 社交（核心机制）
- 社交按 **房间** 隔离，**你能看到消息的范围 = 消息发出时你所在的房间**。
- 页面会显示「XX 进入了房间 / 离开了房间」，并显示头像。
- 若你离开页面（下线或不在 BB House），系统默认你 **仍在当前房间**；你回来后可以看到这段时间该房间的消息。

### 4. HOH 房与门铃
- HOH 房门默认关闭；房客在 **HOH 房门口** 可以「按门铃」。
- HOH 收到门铃提示后决定是否开门。
- HOH 可 **邀请** 指定房客进入 HOH 房；被邀请者确认后进入。
- **只有在 HOH 房或 HOH 房门口** 才能得知 HOH 房门开关状态；**只有在客厅或后院** 才能得知后院门开关状态。
- HOH 房内可以看到 **监控（HOH Monitor）**（仅显示各房间人数）。

### 5. 作息机制：睡眠与洗澡

> 本节规则已按当前版本更新；睡眠时间、单次睡眠时长和洗澡冷却均可由管理员在赛季设置中调整，请以 **BB House 页面实时显示** 为准。

- **睡眠（可主动入睡的时间窗）**：
  - 默认可开始睡觉的时间为 **22:00–02:00**（支持跨日期，管理员可调）。只有在 **可开始睡觉时间** 内、且在可睡觉的房间，才能点击「睡觉」。
  - **每个睡眠周期（以时间窗开始当天计算）只需完成一次睡眠。** 在本周期内已经睡过，页面会提示「本睡眠周期已完成」，不能重复睡。
  - 单次睡眠默认现实 **6 小时（360 分钟）**，管理员可调整。睡眠开始后会显示醒来倒计时；**到时间后不会自动醒来，需要你点击「醒来」**。未到醒来时间无法提前醒来。
  - 睡眠期间 **不能移动**，也无法接收当前房间以外的消息与互动；房间内其他人可以看到你处于睡眠状态。
  - **被动入睡**：如果睡眠时间窗结束时你仍未完成本周期睡眠，系统会 **自动让你进入睡眠**（并在设定的睡眠时长后允许醒来）。窗口结束后才加入的房客不会被追溯到上一个睡眠周期。
  - 贫民只能在贫民屋睡觉；其他房客可在 HOH 房或任意卧室睡觉；非 HOH 房客想在 HOH 房睡觉需 HOH 同意，且受床位限制。
- **洗澡**：
  - **进入浴室即自动开始洗澡**，不需要再点击按钮；洗澡持续现实 **10 分钟**，期间 **不可中途离开浴室**。
  - 洗澡结束后会自动结束并把你移动到 **洗漱间**，同时进入 **洗澡冷却**。
  - 洗澡冷却默认 **30 分钟**（管理员可调）。冷却期间 **不能再次进入浴室洗澡**；洗漱间会显示剩余冷却时间。
  - 现在洗澡 **不限制每天一次**，只要不在冷却中且浴室有空位即可再次洗澡。

### 9.18 Stay or Fold

**规则**
- 每轮分为五个阶段：**观察 → 估算 → 公布估算 → 决定 Stay/Fold → 结算**。

- **估算**：公布目标 emoji，在限时内秘密提交你的估算（每人 1 次）。
- **公布**：展示每位选手的估算值，但 **不公布真实数量与差值**。
- **决定**：选择 **Stay（继续）** 或 **Fold（本轮退出）**。
- **结算**：公布真实数量与各 Stay 选手的差值；**差值最小的 Stay 者 +1 分**；若存在明确的最大差值，则 **差值最大的 Stay 者淘汰**（所有人同差时不淘汰）。

### 9.21 数字占卜术（Number Divination）

**规则**

- 每位玩家持有数字 **1–10**。每轮同时秘密打出 **1 个尚未使用过的数字**，共 **10 轮**（管理员可调）。
- 结算时：
  - 某数字 **没有与他人重复**：打出者获得该数字的分数。
  - 所有未重复数字中 **最大的数字**：得分 **翻倍**。
  - 重复数字中 **重复次数最多** 的数字（可能不止一个）：对应的所有玩家 **扣除该数字的分数**。
- 全部轮次结束后，**总分最高且不并列者获胜**。
- 若并列第一，依次比较：**最后一轮单轮得分**（高者胜）→ **最后一轮提交时间**（更早者胜）。

### 9.22 补充：自定义小游戏（管理员自建）

管理员可以使用「自定义」功能创建不在上表中的比赛，常见为答题/抢答类，支持文字、选项、数字、管理员评判等题型，也可能附带图片、视频或音乐。其页面通常包含：

- 顶部 **计时 / 得分 / 答对题数 / 提交次数 / 冷却**；
- 题干区、选项或数字键盘、提交按钮；
- 单题逐一提交或 **多题一起提交** 两种模式；
- 答题后的对错反馈与最终排名。

自定义对战模式目前包含以下 5 种（具体题目与参数由管理员配置）：

| 模式 | 玩法要点 |
|---|---|
| 最后作答出局 | 全员同时作答，最后作答者出局；或按配置改为「第一个答错者出局」，直到剩 1 人 |
| 首个作答定胜负 | 只检查第一个作答者：答对可任选一人出局，答错则自己出局 |
| 1v1 对决 | 每轮抽取/指定 2 人对决，只检查第一个作答者，胜者回到池中，直到决出最后 1 人 |
| 限时淘汰 + 数字加时 | 限时内可修改答案，锁定后答错或未作答者出局；基本题结束后进入「不超过目标值且最接近」的数字加时题 |
| 限时积分 + 数字加时 | 限时内可修改答案，答对积 1 分；基本题结束后唯一最高分获胜，否则进入数字加时题 |

### 9.23 结果与观战说明

- 所有小游戏的 **胜负、得分、排名均由服务器判定**，页面动画与音效仅用于展示。
- 淘汰制游戏（少数决、顺序记忆、抓小三、Stay or Fold、自定义对战等）被淘汰后会进入 **观战模式**，可以继续看比赛，但不能再操作。
- 若在比赛中刷新页面或短暂断线，重新进入会 **恢复当前状态**，不会重新发牌或重复计分。
- 部分游戏支持管理员设置 **无限时 / 限时**；到达限时后服务器会自动结算，未完成的操作按规则处理。

## 十、实时同步、计时与断线

- **实时同步**：阶段切换、比赛过程、投票、房子内的移动与聊天、门与广播等，均通过实时连接推送，页面会自动更新。
- **计时由服务器统一维护**：所有倒计时以服务器绝对时间为准，避免刷新导致时间错乱。
- **刷新 / 断线重连**：游戏状态保存在服务器，重新进入页面会恢复你的状态，**不会** 重新发牌、重复计分或重复动作。
- **操作幂等**：重复提交同一操作不会重复生效。
- **服务器权威**：所有结果（票数、排名、胜负）均由服务器判定；页面动画只是展示，不能改变结果。
