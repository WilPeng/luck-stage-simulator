# 乘风 2026 · 评分计算细则（选手版）

> 本文用「羊村队 / 狼堡队」等《喜羊羊与灰太狼》角色举例，帮助你理解**个人评级、发挥成绩、团队评级、团队得票、个人喜爱度**每一步是怎么算出来的。

---

## 0. 先认识几个名词

每一轮公演，队伍会选一首歌。每首歌有这些参数：

| 参数 | 含义 | 例子《草原之歌》 |
|---|---|---|
| 难度 d | 骰子面数，越大越难 | 4 |
| 风险值 risk | 每超出/缺少“1 倍风险值”触发一次变化 | 10 |
| 基准声乐 BaseVocal | 声乐至少要达到的值 | 20 |
| 基准舞蹈 BaseDance | 舞蹈至少要达到的值 | 20 |
| 主属性 main | 这首歌主要考的属性（声乐/舞蹈/魅力） | 声乐 |

选手有 3 项属性：**声乐 Vocal、舞蹈 Dance、魅力 Charm**。

角色示例属性（本文明沿用）：

| 选手 | 声乐 | 舞蹈 | 魅力 |
|---|---:|---:|---:|
| 喜羊羊 | 70 | 30 | 60 |
| 美羊羊 | 35 | 25 | 65 |
| 沸羊羊 | 25 | 55 | 30 |
| 懒羊羊 | 15 | 10 | 20 |
| 慢羊羊 | 40 | 15 | 40 |
| 暖羊羊 | 30 | 30 | 55 |
| 灰太狼 | 45 | 55 | 35 |
| 红太狼 | 30 | 25 | 50 |
| 小灰灰 | 20 | 20 | 40 |

## 1. 个人评级（丢骰子）

个人评级只看**声乐、舞蹈**（魅力不影响评级），结果分为 **S / A / B / C / D**（超级完美 / 完美 / 正常 / 翻车 / 超级翻车）。系统先按你的属性算出**每一面骰子对应什么评级**，再由你**亲自点击**掷出 1 个「难度面」骰子，**点数越大评级越低**。

### 1.1 情况一：声乐、舞蹈都达到基准（判定为 A / B / C）

- 主属性基准 = 主属性对应的基准值（主属性=声乐→BaseVocal；=舞蹈→BaseDance；=魅力→(BaseVocal+BaseDance)/2）。
- **超出值 S = 你的主属性 − 主属性基准**（不足则为负，算 0 步）。
- **步数 steps = ⌊S ÷ 风险值⌋**（向下取整）。
- 每 1 步：先把 1 个骰面从 C 变成 B，最多变到「难度−1」面为 B；再继续每 1 步把 1 个骰面从 B 变成 A，最多「难度−2」面为 A。

由此得到骰面数量：

```
A面 = min( max(steps-(d-1), 0), d-2 )
B面 = min(steps, d-1) - A面
C面 = d - A面 - B面
```

**极限（超出非常多）**：A 面 = 难度−2、B 面 = 1、C 面 = 1。

**例子**：喜羊羊（声乐 70、舞蹈 30）唱《草原之歌》（难度 4、风险 10、基准 20/20、主属性 声乐）
- 声乐 70≥20、舞蹈 30≥20 → 达标。
- 超出值 = 70−20 = 50 → steps = ⌊50/10⌋ = 5。
- A面 = min(max(5−3,0), 2) = 2；B面 = min(5,3)−2 = 1；C面 = 4−2−1 = 1。
- 骰子 4 面：**1～2 点 = A，3 点 = B，4 点 = C**。
- 额外：若掷出 1 点、且没有任何未达标、且 steps ≥ 2×难度−3，则升为 **S**。

### 1.2 情况二：声乐或舞蹈未达到基准（会出现 C / D）

先算**未达标差值**（只算“少了多少”，超出不算）：

```
差值 deficit = max(0, 基准声乐−声乐) + max(0, 基准舞蹈−舞蹈)
步数 deficitSteps = ⌈差值 ÷ 风险值⌉   （不足 1 倍按 1 倍算，即向上取整）
x = deficitSteps ÷ 难度
```

- C 的额外概率：`x ≤ 1 时 = x`；`x > 1 时 = max(1/难度, 2−x)`
- D 的额外概率：`x ≤ 1 时 = 0`；`x > 1 时 = min(1−1/难度, x−1)`

把概率换算成骰面（C 面、D 面），**从最好的面（A→B→C）依次扣除**，保证总面数 = 难度。差值极大时，最终 ≈ **1/难度 为 C，其余为 D**。

**例子 1（差值较小）**：慢羊羊（声乐 40、舞蹈 15）唱《草原之歌》（难度 4、风险 10、基准 20/20、主属性 声乐）
- 舞蹈 15<20 → 差值 = 0 + (20−15) = 5 → deficitSteps = ⌈5/10⌉ = 1，x = 1/4 = 0.25。
- C 额外概率 = 0.25 → 额外 C 面 = round(0.25×4) = 1；D 面 = 0。
- 常规超出：声乐 40−20 = 20 → steps = 2 → A面 0、B面 2、C面 2。
- 扣除惩罚后：**B 面 1、C 面 3**。骰子 4 面：1 点 = B，2～4 点 = C。

**例子 2（差值较大，出 D）**：假设某歌难度 2、风险 10、基准 20/20，懒羊羊（声乐 15、舞蹈 10）
- 差值 = (20−15)+(20−10) = 15 → deficitSteps = ⌈15/10⌉ = 2 → x = 2/2 = 1。
- C 概率 = 1 → 额外 C 面 = 2，D 面 = 0。骰子 2 面全是 C。
- 若差值更大（如 30，x = 1.5）：C 概率 = max(0.5, 0.5) = 0.5、D 概率 = 0.5 → **C 面 1、D 面 1**。骰子 2 面：1 点 = C，2 点 = D。

> 记住：**骰子点数越大评级越低**，掷骰由你亲自点击完成。

## 2. 发挥成绩（小游戏）

公演前，每轮会指定一个「发挥值小游戏」，你玩完后的**成绩**会记录为你的发挥成绩（不是分数区间，而是按成绩排名）：

| 小游戏 | 成绩口径 | 排名方向 |
|---|---|---|
| 随机老虎机 | 0～100 | 越大越好 |
| 摆动指针 | 0～100（两侧 0、正中 100） | 越大越好 |
| 手速挑战 | 点击次数（如 60 次） | 越多越好 |
| 策略抉择 | 稳健 30~50 / 均衡 20~70 / 豪赌 0~100 | 越大越好 |
| 反应力 | 反应时间 ms | 越小越好 |
| 记忆配对 / 数字炸弹 / 找不同 / 算术 | 完成用时（秒） | 越小越好 |

发挥成绩**只用于排名**，进而决定你在团队得票里的「发挥后魅力加成」（见第 4 节）。

## 3. 团队评级

团队评级由**成员的个人评级**决定，按管理员配置的规则**从上到下逐条判断，命中第一条即生效**。每条规则可有多个条件，条件之间可选「全部满足(AND)」或「满足任一(OR)」。

**默认规则**（管理员可改）：

| 顺序 | 条件 | 团队评级 |
|---|---|---|
| 1 | 至少 2 人评级 = C | D 惨不忍睹 |
| 2 | 至少 1 人评级 = C | C 翻车 |
| 3 | 至少 2 人评级 = S | S 超级完美 |
| 4 | 至少 2 人评级 ∈ {S, A} | A 完美 |
| 5 | 兜底 | B 正常 |

**例子**：羊村队成员评级分别为 喜羊羊 **A**、美羊羊 **B**、沸羊羊 **C**
- 规则1：C 的人=1（要求≥2）不满足；
- 规则2：C 的人=1 ≥1 → 命中 → **团队评级 = C**。

## 4. 团队得票（公演分数）

团队得票由 **1000 名大众评审**逐人投「是/否」产生，票越多名次越高。

### 4.1 发挥后魅力

先按**发挥成绩排名**给每人一个加成（系统按名次分 5 段，管理员可配置）：

| 段位 | 加成 |
|---|---|
| 前 20% | +20% |
| 20%～40% | +10% |
| 40%～60% | 0 |
| 60%～80% | −10% |
| 后 20% | −20% |

```
发挥后魅力 = 魅力 × (1 + 加成)
```

### 4.2 团队得票率

```
全场最高发挥后魅力 = 所有选手中「发挥后魅力」的最大值
团队得票率 = (队内发挥后魅力均值 + 队内发挥后魅力最高值) ÷ (2 × 全场最高发挥后魅力) × 团队评级权重
```

**团队评级权重**（管理员可配，默认）：S=1、A=0.9、B=0.8、C=0.7、D=0.6。

1000 名评审每人以「团队得票率」为概率投「是」，最终 **得票数 = 投“是”的人数**。

**例子**：羊村队（喜羊羊/美羊羊/沸羊羊），发挥成绩排名分别处于 前20%(+20%)、20~40%(+10%)、40~60%(0)
- 发挥后魅力：喜羊羊 60×1.2 = 72；美羊羊 65×1.1 = 71.5；沸羊羊 30×1.0 = 30
- 均值 = (72 + 71.5 + 30) ÷ 3 = 57.83；最高 = 72
- 假设全场最高发挥后魅力 = 80；团队评级 = A（权重 0.9）
- 得票率 = (57.83 + 72) ÷ (2×80) × 0.9 = 129.83 ÷ 160 × 0.9 ≈ **0.7303（73.03%）**
- 1000 名评审 → 约 **730 票**

> 全队发挥越好、魅力越高、团队评级越高，得票率越高。

## 5. 个人喜爱度（大众评审个人票）

由同一批 1000 名评审，每人投 **3 票**给个人，票数越高个人喜爱度排名越高。

```
个人权重 = 魅力×2 × 个人评级加权 × 团队评级加权 + 队伍排名加成 + 队内MVP加成
```

- **个人评级加权 / 团队评级加权**：同第 4.2（S/A/B/C/D → 1/0.9/0.8/0.7/0.6，可配）。
- **队伍排名加成** = round( 30 × (总队伍数 − 队伍名次) ÷ (总队伍数 − 1) )。
- **队内MVP加成** = 若你在**队内个人排名第 1**，+20；否则 0。
- 评审按每人的「个人权重」加权随机抽取 3 票（权重越大越容易被抽到）。**无任何随机观众缘**。

**例子**：喜羊羊，魅力 60、个人评级 A、团队评级 A、所在队共 3 队且名次第 1、队内第一
- 权重 = 60×2 × 0.9 × 0.9 = 97.2 → 取整 97
- 队伍排名加成 = round( 30 × (3−1) ÷ (3−1) ) = 30
- 队内MVP加成 = 20
- **个人权重 = 97 + 30 + 20 = 147**

## 6. 一张图串起来（完整算例）

以羊村队为例：

1. **个人评级**：喜羊羊当场掷骰 → A；美羊羊 → B；沸羊羊 → C。
2. **团队评级**：命中「至少 1 人 C」→ **C**。
3. **发挥成绩**：三人完成小游戏后按成绩在全场排名，得到魅力加成。
4. **团队得票**：按第 4 节公式算得票率 → 1000 评审投票 → 得票数。
5. **个人喜爱度**：按第 5 节公式得到个人权重 → 1000 评审投 3 票 → 个人喜爱度排名。
6. 得票/喜爱度排名靠后的队伍与个人，进入淘汰环节；淘汰前的 **PK** 环节同样会揭晓得票，并逐位（百/十/个）公布。

## 7. 管理员可配置项一览

| 配置 | 作用 |
|---|---|
| 歌曲 难度 / 风险值 / 基准声乐・舞蹈 / 主属性 | 决定个人评级骰面 |
| 团队评级规则 | 决定团队评级（支持 ≥/≤/>/</= 与 AND/OR） |
| 评级权重（S~D） | 个人喜爱度与团队得票的评级加成 |
| 发挥成绩 5 段加成 | 发挥后魅力加成 |
| 个人/团队评级加权具体值 | 可在管理端修改 |

> 所有数值以管理端当前设置为准，本文默认值仅用于说明。
